Sobre mim

Full-stack developer: criando soluções inteligentes com código e dados

Sou graduando em Análise e Desenvolvimento de Sistemas pelo IFAM e Técnico em Informática formado pelo CETAM.

Atuo no desenvolvimento de aplicações web e mobile, construindo interfaces modernas com React, React Native e Jetpack Compose (Kotlin), além de APIs RESTful e backends robustos com Spring Boot e Laravel. Trabalho com bancos de dados MySQL e MongoDB, soluções em nuvem como Supabase e Firebase, e análise de dados utilizando Python (Pandas) e R.

Perfil dinâmico, proativo e orientado a resultados, sempre em busca de novas tecnologias para transformar desafios técnicos em soluções eficientes e bem estruturadas.
