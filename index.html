Sobre mim

Full-stack developer: criando soluções inteligentes com código e dados

Sou estudante de Análise e Desenvolvimento de Sistemas no IFAM, também estudante do curso Técnico em Informática pelo CETAM.

Desenvolvedor focado em sistemas web e mobile, com experiência na criação de APIs RESTful e integração de interfaces modernas utilizando React para web e React Native e Jetpack Compose (Kotlin) para dispositivos móveis. No backend, utilizo Spring Boot e Laravel para construções robustas, integradas a bancos de dados como MySQL, MongoDB e soluções como Supabase e Firebase para autenticação e serviços em tempo real. Complemento minha atuação com conhecimentos em Ciência de Dados, manipulando e analisando dados com Pandas e R, além de dominar o ecossistema front-end com JavaScript e Bootstrap.

Profissional dinâmico e proativo, com foco em resultados e rápida capacidade de adaptação a novos cenários. Busco constantemente o aprendizado de novas tecnologias para criar soluções organizadas e eficientes, transformando desafios técnicos em resultados práticos e de alto valor.
